INSTRUCCIONES DE USO!
Requisitos

MariaDB 10.x o MySQL 8.x
Cliente SQL: HeidiSQL, MySQL Workbench o DBeaver

Paso 1 — Ejecutar el script principal
Copiar y ejecutar el script de la sección Script de la Base de Datos. Crea la base de datos, todas las tablas, índices y datos de prueba.

Paso 2 — Ejecutar los Stored Procedures
Copiar y ejecutar cada procedimiento de la sección Script de Stored Procedures por separado, desde DELIMITER $$ hasta DELIMITER ;.

En HeidiSQL: seleccionar el bloque completo de cada procedimiento y presionar F9.

Paso 3 — Ejecutar las Vistas
Copiar y ejecutar cada CREATE VIEW de la sección Script de Vistas. Las vistas no necesitan DELIMITER.

Paso 4 — Llamar los procedimientos

-- registrar un cliente
